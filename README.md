# 📚 Dictionary Bot

A Telegram bot for learning new words.

## Description

The bot helps you learn English words:
- Add your own words
- Take tests
- Get daily reminders
- Track your progress

## Commands

| Command | Description |
|---------|-------------|
| `/start` | Start working with the bot |
| `/command` | Show all commands |
| `/count` | Set the number of words per day |
| `/words` | Add new words |
| `/test` | Start a test on your words |
| `/remind` | Set a daily reminder |
| `/list` | Show all your words |
| `/delete` | Delete a word |
